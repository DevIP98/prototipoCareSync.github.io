# CareSync - Plataforma de Gestión de Cuidados para Adultos Mayores

CareSync es un prototipo web desarrollado con HTML, CSS y Bootstrap 5 que proporciona una plataforma integral para la gestión de cuidados de adultos mayores.

## Características Principales

1. **Registro de Pacientes**
   - Formulario de ingreso de datos básicos y médicos con validaciones
   - Listado de pacientes con búsqueda y filtrado
   - Gestión completa de información de contacto y condiciones médicas

2. **Módulo de Alertas**
   - Alertas en tiempo real basadas en signos vitales y actividad
   - Clasificación por nivel de urgencia (alto, medio, bajo)
   - Sistema de notificación y gestión de respuestas

3. **Acceso a Reportes de Salud**
   - Listados exportables en PDF
   - Filtrado por fecha y paciente
   - Visualización de tendencias de salud

4. **Integración con Dispositivos Médicos IoT**
   - Conexión con dispositivos de signos vitales
   - Almacenamiento de datos en la nube
   - Monitoreo continuo automatizado

5. **Portal de Acceso para Familiares**
   - Visualización de información de salud del paciente
   - Comunicación con cuidadores
   - Recepción de notificaciones importantes

## Cómo Usar

1. Descarga o clona el repositorio
2. Abre el archivo `index.html` en tu navegador web
3. Inicia sesión con cualquier correo electrónico y contraseña (modo demo)
4. Explora las diferentes secciones de la plataforma
